# Build the Challenge app

## Scope
- Recreate the mobile-first home dashboard from the first supplied HTML reference.
- Recreate the challenge creation flow from the second reference, accessible from the Create actions.
- Preserve the Portuguese copy, imagery, colorful card styling, fixed header, and bottom navigation.
- Add working interactions for switching screens, selecting challenge options, entering form text, saving a draft, and launching a challenge.

- Establish semantic colors, typography, spacing, shadows, and motion in the global design system.
- Build shared app navigation and reusable controls, then compose the home and creation screens.
